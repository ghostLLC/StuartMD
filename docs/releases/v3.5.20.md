# StuartMD 3.5.20

- 正文支持向前、向后跨段拖动选择。Ctrl+A 首次选择当前段落，本段已经全部选中时再次按下选择全文。
- AI 设置支持保存多个服务商连接和多个模型，日常使用可以直接从已保存模型列表切换。提供国内厂商模型预设、搜索、状态标记和分类页面。
- 完善已有 AI 配置迁移，保留用户配置的模型和密钥。
- 知识检索统一使用 BGE-M3。
- 各文档分别保存阅读位置，切换文件时恢复对应位置。
- 左侧文件目录的刷新操作跟随当前文件所在目录。
- 开始页面使用统一的应用图标，Markdown 文件关联使用专用文档图标。
- Mermaid 选区提供适用的操作，欢迎文档和示例文档同步更新。

适用于 Windows x64。下载并运行 `StuartMD_3.5.20_x64-setup.exe`。本机已经完成从 3.5.19 到 3.5.20 的静默升级，20 项资源检查通过，原有 32 个文件、6 个数据库及 260 条记录保持一致。

42 项前端检查、6 项目录检查、86 项 Rust 主程序检查及 25 项实际文件与进程检查通过。其中包括 12 项选择专项 DOM 检查。

真实 ONNX 模型推理、索引生成与取消、PDFium、OCR，以及 DeepSeek 在线流式回答、预算、摘要和取消检查通过。详细结果保存在仓库的 `docs/validation/3.5.20/` 目录。

按用户要求跳过窗口、浏览器及安装后启动检查；原生鼠标拖选和浏览器焦点行为未进行界面实测。
