# StuartMD

轻量 Markdown 阅读与编辑器。打开、阅读、批注，保持专注。

**项目仓库：** [https://github.com/ghostLLC/StuartMD](https://github.com/ghostLLC/StuartMD)

**当前版本：** 2.0.6

---

## 能做什么

| 场景 | 说明 |
|------|------|
| 读文档 | 美化排版、公式、表格、代码高亮 |
| 写笔记 | 阅读 / 分栏 / 源码三种模式，点击段落直接编辑 |
| 飞书式交互 | 悬停出块手柄，选中出浮动工具栏，块菜单改类型/缩进/剪切复制 |
| 撤销重做 | `Ctrl+Z` 撤销，`Ctrl+Y` / `Ctrl+Shift+Z` 重做 |
| 看 PDF | 竖版横版均可，支持标黄与擦除 |
| 多窗口 | 每个文档可独立开窗对照 |
| 换外观 | 浅色、深色、羊皮纸、小黄人、壁纸 |
| 多语言 | 简体中文、繁體中文、English |

## 快速开始

1. **文件** → 打开文件 / 打开文件夹  
2. 顶部切换 **阅读 · 分栏 · 源码**  
3. `Ctrl+S` 保存；有路径后会自动保存  
4. 设置里可改主题、语言、插件、检查更新  

## 编辑交互（对齐飞书）

- **悬停段落**：左侧出现块手柄（`T ⠿` 一体按钮）  
- **点手柄**：打开块菜单——标题/列表/任务/代码/引用、缩进和对齐、剪切/复制/删除  
- **鼠标离开手柄与菜单**：菜单自动收起  
- **选中文字**：出现浮动栏（样式、对齐、B/S/I/U、链接、代码、颜色）  
- **双击复杂块**（表格 / 公式 / 代码 / Mermaid）：进入源码编辑，失焦立即回到渲染态  
- 单击普通段落：就地轻量编辑

## PDF

- 打开 `.pdf` 即可阅读  
- 点 **标黄** 后选中文字即可高亮  
- **擦除** 模式下点高亮可删除  
- 横版自动适配，可旋转 / 适应宽高  
- 批注保存在 AppData，不修改原 PDF  

## 外观与壁纸

设置 → 外观：

- 浅色 / 深色 / 羊皮纸（阅读向）  
- 小黄人（个性向）  
- **上传壁纸**：自动提取主色作为强调色  

## 插件

将 `.js` 插件放入：

`%APPDATA%\StuartMD\plugins\`

可在设置中启用/停用。开发说明见仓库 `docs/PLUGINS.md`。

## 常用快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+N` | 新建文档 |
| `Ctrl+F` | 查找 |
| `Ctrl+E` | 导出 HTML |
| `Ctrl+P` | 打印 / PDF |
| `Ctrl+T` | 切换主题 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+1/2/3` | 阅读 / 分栏 / 源码 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体（编辑中） |
| `Ctrl+Shift+X` | 删除线 |
| `Ctrl+Alt+1..4` | 一至四级标题 |
| `Ctrl+Shift+7` / `8` | 有序 / 无序列表 |
| `Ctrl+Shift+9` | 任务列表 |
| `Ctrl+B`（未编辑时） | 侧边栏 |

## 安装说明

- 默认安装：`%LOCALAPPDATA%\StuartMD`（可向导自定义路径）  
- 静默安装：`StuartMD-Setup-2.0.5.exe /S`  
- 设置中可**检查更新**；升级时配置、插件、壁纸会自动迁移  
- 欢迎与问题反馈：[GitHub Issues](https://github.com/ghostLLC/StuartMD/issues)
