# StuartMD

轻量 Markdown 阅读与编辑器。打开、阅读、批注，保持专注。

**项目仓库：** [https://github.com/ghostLLC/StuartMD](https://github.com/ghostLLC/StuartMD)

**当前版本：** 2.9.3

---

## 能做什么

| 场景 | 说明 |
|------|------|
| 读文档 | 美化排版、公式、表格、代码高亮 |
| 写笔记 | 阅读 / 分栏 / 源码三种模式，点击段落直接编辑 |
| 飞书式交互 | 悬停出块手柄，选中出浮动工具栏，块菜单改类型/缩进/剪切复制 |
| AI 接口就绪 | `StuartAgent` 文档/大纲/块/选区 + 记忆存储与工具注册（中期 AI 接入点） |
| 撤销重做 | `Ctrl+Z` 撤销，`Ctrl+Y` / `Ctrl+Shift+Z` 重做 |
| 看 PDF | 竖版横版均可，支持标黄与擦除 |
| 多窗口 | 每个文档可独立开窗对照 |
| 换外观 | 浅色、灰色、深色、羊皮纸、小黄人、壁纸 |
| 多语言 | 简体中文、繁體中文、English |

## 快速开始

1. **文件** → 打开文件 / 打开文件夹  
2. 顶部切换 **阅读 · 分栏 · 源码**  
3. `Ctrl+S` 保存；有路径后会自动保存  
4. 设置里可改主题、语言、插件、检查更新  
5. 右上角可切换**页宽**（默认 / 较宽 / 全宽）  

## 编辑交互（对齐飞书）

- **悬停段落**：左侧出现块手柄（`T ⠿` 一体按钮）  
- **点手柄**：打开块菜单（更窄、三行图标）——标题/列表/任务/代码/引用、缩进和对齐、剪切/复制/删除  
- **菜单不挡正文**：较宽/全宽时菜单落在选中内容下方；默认页宽加大侧栏与正文间距  
- **鼠标离开手柄与菜单**：菜单自动收起  
- **选中文字**：出现浮动栏（样式、对齐、B/S/I/U、链接、代码、颜色）  
- **双击复杂块**（表格 / 公式 / 代码 / Mermaid）：进入源码编辑，失焦立即回到渲染态  
- 单击普通段落：就地轻量编辑；单击代码块：进入源码编辑  
- 右键：插入图像 / 链接 / 表格 / 代码块 / 公式 / 分割线 / 段落  
- 列表行首退格：先取消分点，不合并上一行  
- 图表 / 公式不显示块手柄；编辑时手柄仍可唤起

## PDF

- 打开 `.pdf` 即可阅读  
- **标黄默认关闭**：点工具栏标黄图标开启后，选中文字标黄（颜色固定浅黄）  
- **擦除**：标黄关闭时，单击已有高亮选中 → 右键 →「擦除此高亮」  
- **适应**：单个图标，适应高度；**旋转**图标；**双页**并排阅读  
- **Ctrl+滚轮** 缩放；清除全部高亮需二次确认  
- 批注保存在 AppData，不修改原 PDF  

## 外观与壁纸

设置 → 外观：

- 浅色 / 深色 / 羊皮纸（阅读向）  
- 小黄人（个性向）  
- **上传壁纸**：自动提取主色作为强调色  

## 插件

将 `.js` 插件放入：

`%APPDATA%\StuartMD\plugins\`

可在设置中启用/停用。开发说明见仓库 `docs/PLUGINS.md`。

## 常用快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+N` | 新建文档 |
| `Ctrl+F` | 查找 |
| `Ctrl+E` | 导出 HTML |
| `Ctrl+P` | 打印 / PDF |
| `Ctrl+T` | 切换主题 |

| `Ctrl+B`（未编辑时） | 侧边栏 |

## 安装说明

- 默认安装：`%LOCALAPPDATA%\StuartMD`（可向导自定义路径）  
- 静默安装：`StuartMD-Setup-2.0.5.exe /S`  
- 设置中可**检查更新**；升级时配置、插件、壁纸会自动迁移
