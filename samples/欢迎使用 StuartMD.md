# 欢迎使用 StuartMD

**当前版本：3.5.18**

StuartMD 用于阅读 Markdown 与 PDF、编辑笔记、保存批注，以及结合正文和知识资料进行 AI 问答。

## 打开文档

1. 使用 **文件 → 打开文件**，或者按 `Ctrl+O` 选择 Markdown / PDF。
2. 打开 Markdown 后，使用顶部的 **阅读、分栏、源码** 切换模式。
3. 单击段落、表格或代码块进行编辑，按 `Ctrl+S` 保存。
4. 使用 **文件 → 打开文件夹** 浏览工作目录，并在伴读的知识页面建立索引。
5. 点击左侧目录栏的 **刷新**，查看当前文件所在文件夹，并定位当前文档。未保存文档需要保存后使用。

## 编辑、保存与恢复

阅读、分栏和源码模式共享当前文档内容。使用 `Ctrl+Z` 撤销，使用 `Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。切换标签时会提交正在编辑的内容，各个标签分别保留自己的编辑状态。

保存保持已经确认的文件编码和未编辑区域的换行。需要确认编码时，请查看所选编码的完整预览。文件被其他程序修改后，自动保存暂停；冲突界面提供基础内容、本地内容与外部内容，可以检查合并或保存副本。

未保存文档和空正文都会记录草稿。重新启动后，恢复界面可以查看已经持久化的修改。中断的保存操作也保留可检查的内容版本，可以将所需版本保存为独立文件。

## PDF 阅读与批注

打开 PDF 后，可以使用缩放、适应高度、旋转和双页显示。选中文字后，鼠标附近会出现高光、下划线、删除线和评论工具。

新增批注自动保存在本机。点击 **写入 PDF** 后，批注会写入 PDF 文件；随后修改原生批注的颜色、评论或删除批注都会保存该文件。保存会检查外部修改，并保留恢复内容。

清除批注会要求确认，默认保留评论；需要删除评论时选择 **同时清除评论**。使用 `Ctrl+Z` 撤销批注操作，使用 `Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。

## AI 问答

在设置的 **已保存模型 → 添加模型** 中选择服务商、必要区域，填写 API Key 并勾选需要的型号。可以一次添加多个模型，同一连接共用加密密钥。内置型号的名称、地址和容量已经准备好。

顶部与伴读输入区直接选择已保存模型，支持搜索和最近使用；当前选择、默认模型和模型参数会持久保存。切换模型用于后续提问，已经发送的回答继续使用原配置。选中正文后点击 **问答**，或者按 `Alt+E`；按 `Alt+I` 打开伴读面板。

模型条目的 **验证回答** 会发送公开测试消息，检查计数、流式正文和实际用量。服务商连接的 **获取模型目录** 显示在线目录与获取时间。密钥或模型参数修改后，验证状态会更新。**添加其他型号** 可以填写目录外型号、输出预算及计数资料；自定义服务支持新建独立连接或复用已有连接。思考方式中的 **服务默认** 使用服务端默认参数。

回答会逐步显示，可以复制、取消和继续追问。关闭 AI 后停止相关请求。模型需要有效的 Token 计数配置；设置、模型资源或上下文预算不满足要求时，界面显示具体原因。

伴读的 **问答** 页面可以选择选中内容、当前章节、整篇文档和工作区资料。文档会话默认使用整篇文档；当前章节在 PDF 中对应当前页面。切换文档或工作区后，各自的输入草稿和引用会恢复。

点击 **查看本次材料** 可以阅读准备发送的正文、明确引用和适用记忆。答案中的来源入口显示发送时的实际摘录，可以打开原文并定位；正文、文件或索引已经变化时会显示原因。答案支持复制 Markdown、复制纯文本和保存独立笔记。

API Key 使用当前 Windows 用户加密保存。请在软件设置中填写密钥。

## 知识、会话与记忆

打开工作目录后，在 **伴读 → 知识** 点击建立索引。软件自动使用 BGE-M3 准备语义检索资料，首次使用需要联网下载模型资源；完成后可以查询实际文件内容，打开 Markdown 段落或 PDF 来源页面，并引用到问答。

知识状态会显示文件数量、模型、来源变化和未完成的资料。部分索引需要确认后引用。扫描 PDF 的 OCR 结果会报告低置信度内容。

**会话** 页面提供当前目标、当前文档、当前工作区和全部会话筛选，支持搜索、修改名称、分页查看、恢复和删除。恢复历史后可以继续提问；原始问题、各次尝试和回答状态保存在本机。

**记忆** 页面支持新建、搜索、修改、固定、删除、查看来源和历史版本。设置中的 **使用已有记忆** 决定是否在问答中使用适用记录；**整理新记忆** 包含关闭、询问和自动。询问方式选择答案段落后确认保存；自动方式显示独立整理结果，需要确认的内容进入候选列表。保存的记录按照文档、工作区或全局范围使用。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+O` / `Ctrl+N` | 打开文件 / 新建文档 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 阅读 / 分栏 / 源码 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| `Ctrl+F` | 查找 |
| `Alt+E` / `Alt+I` | 选区问答 / 伴读面板 |

外观设置提供浅色、灰色、深色、羊皮纸、小黄人和壁纸主题。插件存放在 `%APPDATA%\StuartMD\plugins\`，首次启用需要确认授权。
