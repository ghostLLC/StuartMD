# 示例文档

**当前版本：3.5.17**

本文包含段落、表格、列表、代码、公式和 Mermaid 图表，用于体验 StuartMD 的阅读与编辑。

## 阅读与编辑

使用顶部的阅读、分栏和源码切换模式。单击段落、表格或代码块可以编辑；选中正文后使用浮动工具栏。保存保持已经确认的文件编码与未编辑区域的换行。

使用 `Ctrl+Z` 撤销，使用 `Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。文件出现外部修改后，可以在冲突界面检查内容并保存副本。未保存文档和空正文均可记录持久化草稿，重启后使用恢复界面继续编辑。

## PDF

打开 PDF 后可以缩放、旋转和双页阅读。选区工具栏支持高光、下划线、删除线与评论。新增批注首先保存在本机；点击写入 PDF 后生成原生批注。修改原生批注会保存实际文件，外部修改引发的冲突会保留恢复内容。

清除操作默认保留评论，可以选择同时清除评论。撤销和重做支持当前文档最近 20 次批注操作。

## AI 与知识资料

在设置的 **已保存模型 → 添加模型** 中选择服务商、必要区域，填写 API Key 并勾选多个模型。同一连接共用密钥；预置型号已经提供地址、思考能力与容量。顶部与伴读输入区从已保存列表直接切换，当前选择、默认模型及最近使用会持久保存。

点击模型的 **验证回答** 会发送公开测试消息并核验计数、流式正文、完成标记与用量；连接的 **获取模型目录** 显示来源及获取时间。修改密钥或模型参数后需要重新验证。**添加其他型号** 支持目录外型号、输出预算、容量及请求参数；自定义服务支持新建独立连接或复用已有连接。思考方式中的 **服务默认** 使用服务端默认参数。

选中 Markdown 或 PDF 正文后按 `Alt+E`，在回答面板继续追问或取消请求。按 `Alt+I` 打开伴读面板。切换模型用于后续请求，已经发送的请求保留原模型配置。

打开工作目录后，在知识页面建立索引。软件自动使用 BGE-M3 进行语义检索。结果包含原文和来源，可以打开 Markdown 段落或 PDF 页面并引用到问答。部分索引和低置信度 OCR 资料会显示具体状态。

问答页面可以选择选中内容、当前章节、整篇文档和工作区资料，并查看本次实际材料。快速问答与伴读面板共享答案和草稿，停止或失败的回答保留实际状态。完整答案可以复制或保存 Markdown 笔记。

会话页面支持搜索、筛选、修改名称、分页读取、恢复原文与继续提问。记忆页面支持新建、搜索、编辑、固定、查看来源及历史版本和删除；“使用已有记忆”与“整理新记忆”分别设置，整理方式包含关闭、询问和自动。
